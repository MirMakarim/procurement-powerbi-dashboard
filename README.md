## The problem

Purchasing teams often track spend, savings and supplier delivery in separate Excel files. Numbers differ between files, and nobody sees the trend. This dashboard puts the four KPIs that matter most on one page, with year-over-year comparison and drill-down by category, region and supplier.

## What's inside

| KPI | Definition |
|---|---|
| **Total Spend** | sum of purchase order line value in EUR, with YoY % |
| **Savings** | negotiated savings against baseline price, as € and % of spend |
| **On-Time Delivery %** | share of PO lines received on or before the requested date |
| **Avg PO Cycle Days** | average days from purchase requisition to purchase order |
| **Single-Source Spend %** | share of spend with suppliers that have no alternative source |

**Data model:** star schema with `PurchaseLines` as the fact table and `Date`, `Suppliers` and `Plants` as dimensions.

```
            Date
              │
Suppliers ── PurchaseLines ── Plants
```

**Dataset:** 15,880 purchase order lines for 2024 and 2025, 60 suppliers, 8 plants, 6 categories. The data is calibrated so the dashboard shows real patterns: autumn peaks, Electronics as the biggest category, delivery performance improving month by month.

## How to build it

Full instructions: [`docs/build-guide.md`](docs/build-guide.md)

1. Load `data/procurement_sample.xlsx` into Power BI Desktop.
2. Add the `Date` table and the measures from `dax/measures.dax`, then create the relationships.
3. Import `theme/procurement-theme.json`.
4. Build the page: 4 KPI cards, monthly spend, spend by category, on-time delivery trend.
5. Check the expected KPI values in the build guide.

To regenerate the data: `python scripts/generate_dataset.py` (needs pandas, numpy, openpyxl).
